PASSO 1 - DESCOBRIR IP LOCAL DO PC (1 min)
========================================
No PowerShell:
  ipconfig
Procure "Adaptador Wi-Fi" ou "Ethernet" -> Endereco IPv4: ex 192.168.1.2 ou 192.168.0.5
Anote. Esse PC hoje esta em 10.0.8.4 / 192.168.1.2 (ver tailscale status Addrs).

========================================
PASSO 2 - LIBERAR FIREWALL WINDOWS (1 min, PowerShell ADMIN)
========================================
Abra PowerShell como Administrador e cole:

  New-NetFirewallRule -DisplayName "WhatsApp Dashboard 3000" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow

Teste na mesma rede (celular no mesmo Wi-Fi):
  http://192.168.1.2:3000/api/health  (troque pelo IP do ipconfig)
Tem que dar {"ok":true}. Se nao der, firewall ainda bloqueia.

Para remover depois:
  Remove-NetFirewallRule -DisplayName "WhatsApp Dashboard 3000"

========================================
PASSO 3 - PORT FORWARD NO ROTEADOR (3 min)
========================================
1. Descubra gateway: ipconfig -> Gateway padrao (ex 192.168.1.1 ou 192.168.0.1)
2. Abra no navegador: http://192.168.1.1  (login esta na etiqueta do roteador, geralmente admin/admin)
3. Procure: "Port Forwarding" / "Encaminhamento de Porta" / "NAT" / "Virtual Server"
4. Crie regra:
   Nome: bot-dashboard
   Protocolo: TCP
   Porta externa: 3000
   Porta interna: 3000
   IP interno: 192.168.1.2  (IP do PASSO 1)
   Ativar: SIM

Dica: alguns roteadores pedem "Origem: Qualquer" e "Destino: 192.168.1.2:3000"

Salve e reinicie roteador se pedir.

e port-forward NAO vai funcionar. Nesse caso unica saida facil sem Tailscale e usar Cloudflare Tunnel

========================================
